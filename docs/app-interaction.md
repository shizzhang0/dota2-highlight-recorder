# 桌面应用交互梳理（2026-10-27 定稿，已按此实现，待实测）

只管交互（有哪些页面、怎么来回走、每一步能做什么），不管视觉。

## 现在的问题

| 问题 | 原因 |
|---|---|
| 结果页同时有"打开输出文件夹"和每个文件的"在文件夹中显示"，重复 | 按钮是边做边加的，没有统一"文件能做什么" |
| 点"返回比赛"后，刚录完的结果再也看不到 | 结果页只是录完那一刻的临时页面，录过什么没有地方留底 |
| 没录完的片段只能在结果页点"继续录剩下的"，离开就没了 | 同上 |
| 比赛页看不出哪些片段已经录过，再录一遍会覆盖同名文件 | 比赛页不知道输出目录里有什么 |
| 没有固定的导航：只有左上角回首页、各页自己的"返回"按钮；录制中点首页没反应也没提示 | 页面之间是临时跳转 |
| 本地没有的比赛只能进游戏下载 | 应用里没有下载入口 |

## 改成什么样

### 1. 固定导航：三个入口

顶部一直显示：**比赛** · **已录视频** · **设置**。

- **比赛**：首页，本地录像 + 按比赛 ID 下载（见第 1.1 节）→ 点进比赛页。
- **已录视频**：所有录过的东西，按"一次录制"分组（见第 3 节）。结果页就是这里的一条记录，什么时候都能回来看。
- **设置**：~~保持对话框形式~~ → 2026-11-10 改成**页面**（三个入口点了都是换页，原来只有它弹框，不一致）。保留「保存」和「撤销修改」按钮；改了没保存就切走时，问保存、不保存还是留在这里。

录制进行中导航变灰，并显示"录制中"。原因是录制期间在主窗口上点任何东西都会触发暂停，所以录制中主窗口只看进度，要操作就用游戏上方弹出的对话框（继续 / 停止）。
2026-11-10 起录制不再暂停（发给 Dota 的输入直接拦下），这个理由不成立了，**录制中导航放开**：可以去看已录视频、改设置、下载录像；
导航上的"录制中"可以点，回到进度页（进度按保存的状态重画）。录完时还在进度页就跳到录制详情，在别的页面就不打扰（有系统通知）。
录制中再点"开始录制"会提示还在录，可以去看进度；一次只能录一场。

### 1.1 首页：本地录像 + 按比赛 ID 下载（2026-10-27 和用户讨论定，同日实测后修改）

```text
本地录像                                                         [刷新]
[输入比赛 ID] [打开 / 下载]  （下载中、失败原因显示在这一行）
录像在 Dota 2 的 replays 目录里，和游戏里点「下载」存的是同一个地方。

比赛 ID      开始时间      我的英雄     胜负   时长
9054110537  10-21 21:02  潮汐猎人     负    35:58   ›
9035205154  10-08 23:51  你不在这场          21:19   ›
```

- **只列本地录像**，不联网。列：比赛 ID、开始时间（录像文件里的结束时间减时长）、我的英雄、胜负、时长。
- **输入比赛 ID**：本地有就打开；没有就经 OpenDota 查到录像地址，从 Valve 服务器下载到 replays 目录，下完打开。
  OpenDota 还没有地址时请它去取，每 10 秒问一次，最多等 2 分钟。
- **删除录像**：勾选一场或多场后点"删除选中的 N 场"，确认后把 .dem 移到回收站（不做每行的删除按钮，容易误点），Dota 2 里也就看不到这场了（国服客户端进某些录像会闪退，用户要能清掉）。
  已录的视频和录制记录不动；录制中不能删。
- **下载失败给确定的原因**，不写"可能"：比赛 ID 不对（OpenDota 没有这场）/ 录像已过期（Valve 服务器返回 404）/
  OpenDota 取不到录像地址（附"可以在游戏的「观战 → 比赛记录」里下载"）/ 其他错误原文（网络等）。

**为什么不做"我的比赛"（OpenDota 的玩家比赛列表）**：2026-10-27 实测，用户账号在 OpenDota 的比赛列表停在 08-19，
而之后的比赛按比赛 ID 查都在、里面也有用户的账号（不是匿名），请 OpenDota 刷新账号后列表也没变。列表会落后几个月，
据此提示"去公开比赛数据"也是错的。按比赛查则一直准确，所以只用它来拿录像地址。
同一天还查到：国服 08-19 的录像两个多月后仍能下载，"超过两周就过期"的估计不成立，过没过期只能真去下。

### 2. 比赛页：片段默认都不勾，标出已经录过的

- 打开比赛页时片段**一个都不勾**，用户自己挑（2026-10-27 用户定）。
- 片段表多一列状态："已录"或空白。判断依据是输出目录里有没有这个片段的同名文件。勾已录的片段会覆盖旧文件，勾的时候提示一句。
- 底部汇总："已选 N 个"，选了已录过的另外注明"其中 M 个会覆盖已有视频"。

### 3. 已录视频：按比赛分组（2026-10-27 用户定）

每次录制都记一笔，存在 `%APPDATA%\dota2-highlight-recorder\history.json`，只存元数据：时间、比赛、玩家、英雄、每个片段的状态和文件路径、停下的原因。不存视频。界面按比赛汇总显示。

**列表**（一行一场比赛，最近录过的在上）：

```text
10-26  比赛 9052676196   幻影刺客                已录 7 个 · 合集      ›
10-25  比赛 9061163732   潮汐猎人、米拉娜（朋友）  已录 3 个 · 2 个未录完 ›
```

**详情**（一场比赛）：

```text
比赛 9052676196 · 10-21 · 37:09                       [去比赛页] [删除这场的记录]

幻影刺客（你）
#  时间           击杀                  状态          操作
6  31:27–31:38   卓尔游侠              已录          播放 · 在文件夹中显示
7  31:57–32:13   司夜刺客、孽主、灰烬之灵 已录          播放 · 在文件夹中显示
5  27:23–27:34   双杀                  未录完
合集                                   已录          播放 · 在文件夹中显示
[继续录未完成的 1 个]

▸ 录制记录（展开）
  10-26 22:24  录 6、7   录完了，2.9 分钟
  10-26 22:02  录 6、7   已停止 1/2（检测到鼠标或键盘操作）
```

- 一场比赛里录过几个玩家，就分几个小节。
- 同一个片段录过多次，只显示最新的文件（文件名相同，后录的会覆盖前面的）。
- **文件操作统一成两个**：每个文件"播放"（用系统默认播放器打开）和"在文件夹中显示"。页面上不再单独放"打开输出文件夹"，那个放到设置里输出目录的旁边。
- 文件已经被删掉或移走的，状态显示"文件不在了"，不显示操作。
- "继续录未完成的"只在有选过但没录完的片段时出现，点了走正常的录制确认流程。
- "录制记录"默认折叠：每次录制的时间、录了哪些、结果、停下的原因。更细的经过在运行日志里。
- **删除这场的记录**：弹窗确认，里面有一个勾选项"同时删除视频文件"，默认不勾（2026-10-27 用户定）。勾上的话视频移到**回收站**，不直接永久删除。
- 录完（不管完成、停止还是出错）自动跳到这场比赛的详情。记录一直留在"已录视频"里。

### 4. 录制过程

不变的部分：
- 开始前确认 → 进度窗（游戏上方）+ 主窗口进度页；
- 暂停时游戏上方弹对话框（继续 / 停止），主窗口同步显示；
- 停止或录完后，主窗口切到前面，显示这次录制的详情。

要改的：
- **主窗口进度页的"停止"按钮去掉**。录制中去主窗口点按钮，本身就会先触发暂停，所以停止统一走暂停对话框，免得同一件事有两个入口。
- 中途要问的问题（比如是否重启游戏）和暂停一样，用游戏上方的对话框。主窗口也会显示，两边哪边先答都行。

### 5. 游戏

- 全部录完自动退出 Dota（设置里可以关）；停止或出错时保留游戏，方便接着录。
- 详情页在游戏还开着的时候显示"退出游戏"按钮。这个按钮和具体某条记录没有关系，放在导航栏右侧更合适：只要录制用的 Dota 还开着，就显示"游戏运行中 · 退出"。

### 6. 界面改版：深色、图像化（2026-11-11 用户定）

用户觉得原来的界面"太普通了，全是文字"。先做了效果图（真实比赛数据），用户看过后定：

- **深色主题**，强调色用图标的锈红；时间、比分这类数字用 Windows 自带的 Bahnschrift。只有深色一套，不跟随系统的浅色。
- **英雄图片**取自 Valve 自己的图片服务器（`cdn.cloudflare.steamstatic.com/apps/dota2/images/dota_react/heroes/`，大图 `<英雄>.png`、小图标 `icons/<英雄>.png`），只用英雄名请求；连不上就显示文字。
- **首页**：录像变成卡片，大图是你玩的英雄，角上标胜负、已录几段；比赛 ID、时长、日期用数字字体。悬停可以勾选、批量删除。
- **比赛页**：十个英雄用大图卡片（天辉一行、夜魇一行），选中的人红框加"你"；新增**高光时间线**：整场比赛一条线，红块是片段，上面挂被杀英雄的小图标；
  片段改成**紧凑列表**（两列，一行一个片段），被杀英雄用小图标排开，多杀就多几个，标出双杀、三杀和"已录"（用户特意要求：大图放不下多个击杀）。
- **已录视频**：按比赛分组，每个视频一张缩略图（用 ffmpeg 从视频里取一帧，缓存在 `%LOCALAPPDATA%\dota2-highlight-recorder\thumbs`），
  点缩略图播放；没录完的片段显示成虚线框"接着录"。
- **录制中**：上面大块显示正在录的片段（英雄大图、时间、被杀英雄、这一段的进度），下面一排小卡片是全部片段的状态，详细记录折叠起来。
- 设置页只换配色，布局不变。

改版后用户试用（2026-11-11）提的两处交互：
- **比赛列表**加一种列表看法，右上角「卡片 | 列表」切换，记住上次选的（存在本机浏览器存储里）。
- **已录视频**原来分两层（列表 → 详情），详情页的缩略图和列表一样，按钮"详情""去比赛页"说不清去哪，比赛页也回不来。改成一层：
  每场比赛一块，右上角「详情」（去比赛页，看十个英雄、挑别的片段或别的人再录；原叫「再录几段」，用户改的）和「删除记录」，缩略图下面折叠的「录制记录」；去掉详情页。
  录完回到「已录视频」，顶上显示这次的结果，刚录的那场排第一。比赛页左上角有返回，从哪进来就回哪（比赛列表或已录视频）。
- **去掉系统标题栏**（用户定）：系统那条标题栏跟着 Windows 主题是白的，和深色界面不搭。导航栏兼当标题栏：空白处拖动窗口、双击最大化，
  最右边自己画最小化、最大化（最大化后变成还原）、关闭三个按钮。代价：没有 Windows 11 悬停最大化按钮时的分屏浮窗（Win+方向键、拖到屏幕边缘照样能分屏），没有标题栏右键菜单。

2026-11-12 细节：
- **第一页统一叫「本地录像」**（用户定）：原来导航叫「比赛」、页标题叫「本地录像」、比赛页返回叫「← 比赛列表」，三处不一样。
  现在导航、页标题、返回都叫「本地录像」（英文 Local replays）。
- **设置页标题**和别的页一样，是卡片外面的大标题，原来是卡片里的小标题。
- 首页的「打开 / 下载」用户想再改，还没定怎么改。

## 已定（2026-10-27）

1. 比赛页的片段默认都不勾。
2. "已录视频"按比赛分组，比赛里再按玩家分。
3. 删除记录时提供"同时删除视频文件"的选项，默认不勾，勾上就把视频移到回收站。
4. 首页只列本地录像，加"按比赛 ID 下载"；不做"我的比赛"（OpenDota 的玩家比赛列表不可靠，见第 1.1 节）。
